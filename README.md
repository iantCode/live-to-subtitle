# Live to Subtitle

**중국어 라이브 방송을 한국어 실시간 자막으로 바꿔 OBS 에 띄우는 프로그램** (Windows)

PC 에서 재생 중인 중국어 방송 소리를 듣고, GPU 로 음성을 인식해 적당한 길이의 문장으로 자른 뒤,
OpenAI 모델로 번역해 OBS 브라우저 소스 오버레이로 보여 줍니다.
게임 방송처럼 고유명사가 많은 방송은 용어집을 넣으면 정확도가 크게 오릅니다.

```
PC 소리 (WASAPI loopback)
  └▶ Silero VAD + Whisper large-v3-turbo (GPU, 0.4초마다 다시 인식)
       └▶ 문장 분할 (jieba 단어 경계)
            └▶ OpenAI 번역 (용어집 + 발음 힌트, 다음 말을 참고해 한 번 더 다듬기)
                 └▶ 로컬 서버 (WebSocket) ─▶ OBS 브라우저 소스
```

**특징**
- 말이 끝나고 약 2~3초면 번역이 나옵니다. OBS 에서 방송을 몇 초 늦추면 자막이 **말이 시작될 때** 뜹니다.
- 늦춘 시간 동안 뒤이어 들린 말을 참고해 번역을 한 번 더 다듬어 정확도를 높입니다.
- 음성 인식이 고유명사를 비슷한 소리의 엉뚱한 글자로 적어도(`斗音` → `抖音`) 용어집과 병음으로 찾아 바로잡습니다.
- 터미널 대시보드: 입력 음량, 지금 들리는 말, 최근 자막, 지연 통계를 한눈에 보고 키 하나로 조작합니다.

## 요구 사항

| 항목 | 내용 |
|---|---|
| 운영체제 | Windows 10 / 11 (소리 캡처에 WASAPI 사용) |
| GPU | NVIDIA (CUDA). 그래픽 메모리 약 2GB 사용. RTX 5080 에서 측정 |
| Python | 3.10 이상 (3.12 권장). 없으면 [uv](https://docs.astral.sh/uv/) 로 자동 설치 |
| OpenAI API 키 | 번역에 사용 (https://platform.openai.com/api-keys) |
| OBS Studio | 브라우저 소스 사용. 33.0 에서 확인 |
| 인터넷 | 번역 API, 첫 실행 때 Whisper 모델(약 1.6GB) 다운로드 |

## 설치

### 1. 내려받기
GitHub 에서 **Code → Download ZIP** 으로 받아 원하는 폴더에 풀거나, `git clone` 합니다.
폴더 경로에 한글이나 공백이 없으면 문제가 적습니다 (예: `D:\live-to-subtitle`).

### 2. Python 또는 uv 준비
`setup.bat` 은 Python 이 있으면 그것을 쓰고, 없으면 uv 로 Python 3.12 가상환경을 만듭니다.

- **Python 이 이미 있다면** 그대로 다음 단계로 갑니다.
- **Python 이 없다면** (권장) uv 를 설치합니다. PowerShell 에 아래 한 줄을 붙여 넣고, **새 창**을 열어 다음 단계를 진행하세요.
  ```powershell
  powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
  ```
  uv 는 Python 을 시스템에 설치하지 않고 이 프로젝트의 가상환경(`.venv`) 안에서만 씁니다.
- 또는 https://www.python.org 에서 Python 3.12 를 설치해도 됩니다 (설치 화면에서 **Add python.exe to PATH** 체크).

### 3. setup.bat 실행
`setup.bat` 을 더블클릭합니다. 다음을 차례로 합니다.
1. Python 확인 (없으면 uv 사용)
2. 가상환경 `.venv` 만들기
3. 패키지 설치 (처음에는 몇 분)
4. Whisper 모델 다운로드(약 1.6GB)와 GPU 점검

마지막에 `설치 완료!` 가 나오면 끝입니다. `config.toml` 도 이때 만들어집니다.

### 설치가 어렵다면
오류 메시지를 이해하기 어렵거나 환경이 조금 다르면, **Claude Code** 나 **Codex** 같은 AI 코딩 도구에 맡길 수 있습니다.
이 폴더를 연 상태에서 이렇게 요청해 보세요.

> README.md 를 읽고 이 프로젝트를 내 PC 에 설치해 줘. 중간에 오류가 나면 원인을 찾아서 해결해 줘.

이런 도구는 내 PC 에서 직접 명령을 실행하므로, 무엇을 하려는지 확인하면서 진행하세요.
API 키 같은 비밀 값은 채팅에 붙여 넣지 말고 아래처럼 프로그램 화면에서 직접 입력하는 것이 안전합니다.

### 4. OpenAI API 키
처음 `run.bat` 을 실행하면 키를 묻는 창이 뜹니다. 붙여 넣고 Enter 를 누르면 프로젝트 폴더의 `.env` 에 저장되고
바로 연결을 확인합니다. 나중에 바꾸려면 대시보드에서 `K` 를 누르세요.
(직접 하려면 `.env.example` 을 `.env` 로 복사하고 `OPENAI_API_KEY=sk-...` 를 적습니다.)

## 실행

`run.bat` 을 실행하면 터미널 대시보드가 뜹니다.

```

│ 상태      ● 듣는 중   스피커 (Realtek)   ▮▮▮▮▮▮▮▯▯▯▯▯▯▯▯   -36 dB      │
│ 인식      large-v3-turbo / cuda   GPU 4.6/16GB  21%                          │
│ 번역      gpt-6-luna   API 214회   다시 번역 켜짐                            │
│ 오버레이  http://127.0.0.1:8765/  연결 1개                                   │
│ 방송 지연 10초  (OBS 영상 지연·싱크 오프셋도 같은 값)                        │
╰────────────────────────────────────────────────────────────────────────────╯
╭ 지금 들리는 말 ────────────────────────────────────────────────────────────╮
│ 然后这个地图的话我们其实                                                     │
╰────────────────────────────────────────────────────────────────────────────╯

╰────────────────────────────────────────────────────────────────────────────╯
╭ 통계 ──────────────────────────╮╭ 로그 ────────────────────────────────────╮
│ 말 끝→번역  중앙 2.3s p90 3.6s ││ 13:03:39 [server] OBS 브라우저 소스: ...  │

```

| 키 | 동작 |
|---|---|
| `P` | 일시정지 / 다시 시작. 멈춘 동안에는 새 문장을 번역하지 않습니다 (광고·쉬는 시간, API 비용 절약) |
| `+` / `-` | 방송 지연 1초 늘리기 / 줄이기. 오버레이에 바로 반영되고 `config.toml` 에 저장됩니다 |
| `O` | 자막 모양 미리보기 페이지 열기 |
| `L` | 브라우저 로그 페이지 열기 (중국어 원문 + 번역 기록) |
| `C` | 오버레이 URL 을 클립보드에 복사 (OBS 브라우저 소스에 붙여 넣기) |
| `K` | OpenAI API 키 입력 / 변경 |
| `Q` | 종료 |

- 최근 자막의 `✓` 는 뒤이어 들린 말을 참고해 다시 다듬은 번역이고, 숫자는 말이 끝나고 번역이 나오기까지 걸린 시간입니다.
- 음량 막대가 움직이지 않으면 소리가 프로그램에 들어오지 않는 것입니다 ([문제 해결](#문제-해결)).
- 대시보드 대신 예전처럼 로그만 보려면 `run.bat --plain`.

**실행 옵션**
```
run.bat --list-devices              오디오 장치 목록
run.bat --device "Realtek"          특정 재생 장치의 소리 캡처
run.bat --input --device "CABLE"    입력 장치 (마이크 / 가상 오디오 케이블)
run.bat --file sample.mp4           파일로 테스트
run.bat --plain                     대시보드 없이 로그만 출력
run.bat --config other.toml         다른 설정 파일 사용
```

## OBS 연결

### 자막 소스 추가
1. OBS → 소스 `+` → **브라우저**
2. URL `http://127.0.0.1:8765/` (대시보드에서 `C` 로 복사), 너비·높이는 방송 캔버스와 같게 (예: 1920×1080)
3. **'화면에 보이지 않을 때 소스 종료'는 끄세요.** 켜 두면 장면을 바꿀 때마다 연결이 끊겼다 다시 붙습니다.

배경은 투명하고, 프로그램을 다시 켜도 1초 안에 자동으로 다시 연결됩니다.
OBS 를 다른 PC 에서 돌리면 `config.toml` 의 `[server] host` 를 `"0.0.0.0"` 으로 바꾸고 방화벽에서 8765 포트를 열어 주세요.

### 번역할 소리만 들어가게 하기
기본값(`loopback`)은 PC 에서 나는 **모든 소리**를 듣습니다. 방송 중에는 후원 알림·TTS·배경음악·디스코드 소리까지
인식해 엉뚱한 자막이 생길 수 있으니, 중국어 방송 소리만 따로 받는 것을 권장합니다.
- 방법 1: 중국어 방송을 트는 브라우저의 출력 장치를 별도 장치로 지정
  (Windows 설정 → 소리 → 볼륨 믹서에서 앱별 출력 장치 선택) 하고 `run.bat --device "그 장치 이름"`
- 방법 2: VB-CABLE 같은 가상 오디오 케이블로 보내고 `run.bat --input --device "CABLE"`.
  OBS 에도 같은 케이블을 오디오 입력으로 추가하고 모니터링으로 들으면 됩니다.

장치 이름은 `run.bat --list-devices` 로 확인합니다. 자주 쓰는 장치는 `config.toml` 의 `[audio] device` 에 적어 두세요.

## 자막을 말에 맞추기 (방송 지연)

번역은 말이 끝나고 2~3초 뒤에 나옵니다. 그래서 시청자에게 보내는 **중국어 방송 화면·소리를 OBS 에서 몇 초 늦추고**,
같은 초를 `config.toml` 의 `[server] delay` 에 적으면 자막이 말이 시작될 때 뜹니다 (영화 자막처럼).

**기본값: 10초.** 99% 의 자막이 말과 맞습니다.

늦춘 시간은 정확도에도 씁니다. 자막이 화면에 뜨기 약 1.8초 전에, 그 사이 들린 **다음 말을 참고해 다시 번역**합니다.
중간에 잘린 문장이나 잘못 인식된 말을 뒷말로 바로잡아 의미 점수가 약 4점 오릅니다.
한 번 화면에 뜬 자막은 바뀌지 않습니다.

**OBS 설정** (번역 프로그램은 늦추지 않은 원래 소리를 들어야 합니다)
1. 중국어 방송을 띄운 소스 → 필터 → **영상 지연(비동기)** 10000ms
   (미디어 소스·캡처 장치에서 쓸 수 있습니다. 창 캡처·브라우저 소스는 이 필터가 없어 '렌더 지연'(최대 500ms)을 여러 개 겹쳐야 합니다.)
2. 오디오 고급 속성 → 그 소스의 **싱크 오프셋** 10000ms
3. 대시보드의 `방송 지연` 이 같은 값인지 확인 (`+`/`-` 로 바꾸면 `config.toml` 에도 저장)

'설정 → 고급 → 방송 지연'은 자막까지 함께 늦추므로 이 용도로는 쓰지 않습니다.
지연을 쓰지 않으려면 `delay = 0` (자막을 받는 즉시 표시, 다시 번역도 하지 않음).

| 방송 지연 | 말과 자막이 맞는 비율 | 정확도 |
|---|---|---|
| 10초 (기본) | 99% | 가장 높음 |
| 8초 | 97% | 다시 번역이 제때 끝나는 줄이 줄어 약 1점 낮음 |
| 6~7초 | `[segment]` 를 짧은 줄(15 / 24 / 6.0)로 바꾸면 88~95% | 문장이 잘게 잘려 약 3~5점 낮음 |

**지연에 드는 메모리.** OBS 의 지연 필터는 압축하지 않은 화면을 지연 초만큼 쌓아 둡니다.
메모리는 대략 `해상도 × 초당 프레임 × 초` 에 비례합니다 (1080p·60fps 로 10초면 약 5GB, 30fps 면 약 2.5GB. OBS 포럼 보고를 바탕으로 한 추정).
원본 방송이 30fps 라면 OBS 출력도 30fps 로 하면 절반이 됩니다. 그래픽 메모리가 부족해지면 음성 인식이 느려져
자막이 더 늦어지니, 방송 중 작업 관리자에서 GPU 전용 메모리를 확인하세요.

## 오버레이 모양

대시보드에서 `O` 를 누르면 여러 모양을 밝은/어두운 화면 위에서 나란히 비교하는 미리보기가 열립니다.
마음에 드는 모양의 주소를 OBS 브라우저 소스 URL 로 쓰면 됩니다. 자막은 **확정된 번역만, 한 줄씩** 표시됩니다.

| 파라미터 | 기본 | 설명 |
|---|---|---|
| `style` | box | `box` 반투명 검은 상자 / `outline` 검은 테두리 글자 / `clean` 그림자만 |
| `opacity` | 0.72 | `style=box` 상자의 진하기 (0~1) |
| `size` | 46 | 글자 크기(px). 1080p 기준 42~52 권장 |
| `color` | ffffff | 글자 색 (`#` 없이) |
| `hold` | 7 | 다음 자막이 없을 때 몇 초 뒤 사라질지 |
| `zh` | 0 | 1 이면 중국어 원문도 아래에 작게 표시 |
| `pos` | bottom | `bottom` / `top` |
| `font` | Pretendard | 글꼴 (인터넷이 없으면 맑은 고딕) |
| `delay` | (config) | 방송 지연. 비우면 `config.toml` 의 `[server] delay` |
| `demo` | 0 | 1 이면 프로그램 없이 예시 자막을 반복 재생 |

예: `http://127.0.0.1:8765/?size=48&style=outline`

번역이 실패한 줄은 중국어 원문이 그대로 표시됩니다.
브라우저 소스 대신 OBS '텍스트(GDI+)' 소스를 쓰려면 `[server] text_file` 에 파일 경로를 적으세요.

## 설정 (config.toml)

`setup.bat` 이 `config.example.toml` 을 복사해 만듭니다. 각 항목에 설명 주석이 있습니다. 자주 바꾸는 것:

| 위치 | 항목 | 설명 |
|---|---|---|
| `[audio]` | `source`, `device` | `loopback`(PC 소리) / `input`(마이크·가상 케이블) / `file`, 장치 이름 일부 |
| `[asr]` | `model` | `large-v3-turbo`(권장). `large-v3` 는 느리고 이 용도에서 더 정확하지 않았음 |
| `[asr]` | `corrections` | 음성 인식이 반복해서 틀리는 말의 교정표 (`活属性 = 火属性`) |
| `[segment]` | `soft_max_chars` / `max_chars` / `max_sec` | 자막 한 줄 길이 (기본 18 / 30 / 9.0) |
| `[segment]` | `vad_threshold` | 배경음악이 커서 엉뚱한 자막이 나오면 0.6~0.7 로 |
| `[translate]` | `model`, `effort` | 번역 모델 (기본 `gpt-6-luna`, `none`) |
| `[translate]` | `style` | 방송 성격·말투 지시 (예: "게임 방송. 해요체") |
| `[translate]` | `glossary` | 핵심 용어 `中文 (pīnyīn) = 한국어` ([용어집](#용어집-고유명사-맞추기)) |
| `[translate]` | `glossary_file` | 용어집 파일 (`중국어<TAB>한국어<TAB>분류`) |
| `[translate]` | `refine` | 다음 말을 참고해 다시 번역 (API 호출 약 2배). 끄면 비용 절약 |
| `[translate]` | `draft` | 말하는 도중 임시 번역 (오버레이에는 안 보임, 로그 페이지용). 기본 꺼짐 |
| `[server]` | `delay` | 방송 지연 초 |
| `[server]` | `port`, `host` | 오버레이 주소 (기본 `127.0.0.1:8765`) |

**번역 모델.** `gpt-6.1-terra` 는 luna 보다 의미 점수가 약 8점 높지만 요금이 비쌉니다.
terra 를 쓰면서 임시 번역도 켜려면 `draft_model = "gpt-6-luna"` 로 임시 번역만 빠른 모델에 맡길 수 있습니다.

## 용어집 (고유명사 맞추기)

Whisper 는 고유명사를 같은(비슷한) 소리의 다른 글자로 적는 일이 잦습니다 (`抖音` → `斗音`).
게임·스트리머 이름처럼 방송마다 다른 용어는 아래 네 가지로 알려 주면 정확도가 크게 오릅니다.

1. **핵심 용어** `[translate] glossary`: 매번 번역 모델에 알려 주는 용어. 한 줄에 `中文 (pīnyīn) = 한국어`.
   병음을 함께 적으면 음성 인식이 다른 글자로 적어도 소리로 맞춰 번역합니다.
   진행자 별명, 자주 나오는 캐릭터·지역 이름을 넣으세요.
   ```toml
   glossary = """
   # 진행자
   小林 (xiǎo lín) = 샤오린
   # 이번 업데이트
   星海城 (xīng hǎi chéng) = 별바다 도시
   """
   ```
2. **용어집 파일** `[translate] glossary_file`: 수백~수천 개의 공식 이름. `중국어<TAB>한국어<TAB>분류` 형식
   ([glossary/example.tsv](glossary/example.tsv)). 번역할 문장에 실제로 나온 용어만 골라 알려 주므로 속도에 영향이 없습니다.
3. **발음 힌트** `[translate] sound_alike = true` (기본): 문장과 용어를 병음으로 바꿔 **소리가 같은 용어**를 찾아
   "이 문장의 `斗音` 은 `抖音`(틱톡)일 것" 이라고 알려 줍니다. 흔한 말을 잘못 잡지 않도록 2글자 용어는
   핵심 용어와 분류가 `name` 인 이름만, 소리가 완전히 같을 때만 찾습니다.
4. **교정표** `[asr] corrections`: 반복해서 틀리는 말을 인식 단계에서 바꿉니다 (`틀린 글자 = 맞는 글자`).
   화면에 보이는 중국어와 다음 인식의 문맥까지 바뀌고, 다른 단어의 일부는 건드리지 않도록 jieba 단어 경계에서만 바꿉니다.

방송 성격과 말투는 `[translate] style` 에 적습니다 (예: `"게임 개발자 라이브 방송. 시청자에게 말하는 해요체로 통일."`).

## 동작 원리

**문장 자르기.** 0.4초마다 아직 확정되지 않은 오디오 전체를 다시 인식하고, 아래 순서로 자막 한 줄을 확정합니다.

1. **침묵**: 말이 0.6초 이상 끊기면 지금까지를 확정 (길면 문장부호로 나눔)
2. **문장 끝**: 연속 두 번의 인식이 똑같이 동의한 부분에 。！？ 가 있으면 거기서 확정
3. **절**: 쉼표·짧은 쉼(0.25초)·접속사(因为/所以/然后…) 앞은, 말해진 지 0.7초가 지나면 확정
4. **길이**: 18자를 넘으면 쉼표, 없으면 접속사 앞에서 확정
5. **강제**: 30자 / 9초를 넘으면 쉼표 > 접속사 > 가장 긴 쉼 순으로 자름

모든 분할은 jieba 단어 경계에서만 일어나고, `的`·`一个` 처럼 뒤에 말이 이어져야 하는 단어 뒤에서는 자르지 않습니다.

**번역을 빠르게.** 0.1초마다 VAD 로 말 끝을 살펴, 말이 멈춘 것이 보이면 확정을 기다리지 않고 번역을 먼저 요청합니다.
확정된 문장이 그 문장과 같으면 결과를 그대로 쓰고, 요청이 1.5초 안에 끝나지 않으면 같은 요청을 하나 더 보내 먼저 끝나는 쪽을 씁니다.

**번역을 정확하게.** 직전 4줄의 원문·번역, 방송 성격, 문장에 나온 용어와 발음 힌트를 함께 보냅니다.
방송 지연을 쓰면 자막이 뜨기 직전에 뒤이어 들린 말까지 참고해 한 번 더 번역합니다.

## 성능

RTX 5080 + gpt-6-luna, 실제 중국어 라이브 방송 기준.

| 항목 | 값 |
|---|---|
| 말 끝 → 번역 완료 | 중앙 약 2.3초, p90 약 3.6초 |
| 방송 지연 10초에서 말과 자막이 맞는 비율 | 99% |
| 82분 연속 실행 | 1,788줄 처리, 오류 0, 메모리 증가 없음, 지연 일정 |
| 번역 정확도 (공식 한국어 자막과 의미 비교, 100점) | 약 77점 (그 게임의 용어집을 넣은 경우) |

정확도는 중국 게임 개발사의 라이브 방송 다시보기(사람이 만든 공식 한국어 자막 포함)를 실시간으로 넣고, 30초 구간마다
공식 자막과 의미가 얼마나 같은지 상위 모델로 채점한 값입니다. 용어를 보강할 때마다 4~9점씩 올랐습니다.
측정 방법과 시험한 설정별 결과는 [docs/BENCHMARKS.md](docs/BENCHMARKS.md) 에 있습니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 음량 막대가 움직이지 않음 | 소리가 나는 장치를 듣고 있는지 (`run.bat --list-devices`, `[audio] device`) |
| 자막이 OBS 에 안 뜸 | 대시보드의 `오버레이` 가 `연결 1개` 인지. URL·포트, '화면에 보이지 않을 때 소스 종료' 끄기 |
| 번역 대신 중국어가 뜸 | API 키 (`K` 로 다시 입력), 로그 창의 빨간 메시지 (요청 한도·결제) |
| 엉뚱한 자막이 섞임 | 알림음·음악까지 듣고 있지 않은지 ([번역할 소리만 들어가게 하기](#번역할-소리만-들어가게-하기)), `vad_threshold` 올리기 |
| 자막이 말보다 늦게 뜸 | OBS 의 영상 지연·싱크 오프셋과 `delay` 가 같은지, 대시보드 `제때 표시` 비율, GPU 메모리 부족 여부 |
| 이름·용어가 틀림 | `[translate] glossary` 에 `中文 (pīnyīn) = 한국어` 추가, 반복되면 `[asr] corrections` |
| `setup.bat` 실패 | 마지막 오류 메시지 확인, [설치가 어렵다면](#설치가-어렵다면) |
